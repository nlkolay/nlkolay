# Николай Ткаченко | Infrastructure & SRE Engineer 🛠️

Привет! Я T-shaped инженер с бэкграундом в телекоммуникациях. Специализируюсь на Linux, сложных сетях, автоматизации на Python и проектировании отказоустойчивой инфраструктуры.

Мой фокус — это SRE (Site Reliability Engineering), Network Security и Infrastructure as Code (IaC).

### 🔧 Мой технологический стек:
* **Инфраструктура:** Proxmox VE, Linux (Debian, OpenWrt, Alpine), Docker.
* **Сети & ИБ:** eBPF (dae), nftables/iptables, Xray, WireGuard, Caddy, Zero Trust Architecture.
* **Автоматизация:** Python (FastAPI, aiohttp, Telethon), Bash.
* **Мониторинг:** MQTT, Prometheus, Uptime Kuma, Home Assistant.
